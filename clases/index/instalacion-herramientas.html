CIENCIA DE DATOS CON PYTHON + IA

Instalación de
herramientas

Python · Visual Studio Code · Node.js · Agentes de IA (Claude Code, Codebuff) · Git y GitHub

PASO 01 · LENGUAJE

Python

El lenguaje con el que trabajaremos todo el curso.

  1. 1
    Entra a python.org/downloadsEl botón amarillo descarga la última versión estable.
  2. 2
    Ejecuta el instalador descargadoEn Mac: abre el archivo .pkg y sigue el asistente.
  3. 3
    Marca la casilla Add python.exe to PATHEstá abajo en la primera pantalla — es el paso que más se olvida.
  4. 4
    Haz clic en Install Now y espera a que termine
  5. 5
    Abre una terminalWindows: busca "PowerShell" · Mac: busca "Terminal".
  6. 6
    Verifica: python --versionDebe responder algo como Python 3.13.x. En Mac usa python3 --version.

→ avanza paso a paso

PASO 02 · EDITOR

Visual Studio Code

Nuestro entorno de trabajo: aquí escribimos y ejecutamos el código.

  1. 1
    Entra a code.visualstudio.com y descarga para tu sistema
  2. 2
    Instala con las opciones por defectoRecomendado: marca "Agregar acción Abrir con Code al menú contextual".
  3. 3
    Abre VS Code y ve al panel de extensionesIcono de cuadros en la barra izquierda o Ctrl+Shift+X.
  4. 4
    Instala la extensión Python (Microsoft)
  5. 5
    Instala la extensión Jupyter (Microsoft)Nos permitirá trabajar con notebooks dentro del editor.
  6. 6
    Abre tu carpeta de trabajo: Archivo → Abrir carpetaCrea una carpeta llamada curso-datos para todo el curso.

→ avanza paso a paso

PASO 03 · REQUISITO PARA LOS AGENTES

Node.js

Los agentes de IA se instalan con npm, que viene incluido con Node.js.

  1. 1
    Entra a nodejs.orgDescarga la versión LTS (soporte extendido).
  2. 2
    Ejecuta el instalador con las opciones por defectoSiguiente → Siguiente → Instalar. No cambies nada.
  3. 3
    Cierra y vuelve a abrir la terminalNecesario para que reconozca los nuevos comandos.
  4. 4
    Verifica: node --version y npm --versionAmbos deben responder con un número de versión.

→ avanza paso a paso

PASO 04 · AGENTE IA

Claude Code

Un agente de IA que escribe y ejecuta código contigo desde la terminal.

  1. 1
    Crea tu cuenta en claude.ai si aún no la tienes
  2. 2
    Instala en la terminal: npm install -g @anthropic-ai/claude-codeRequiere el Node.js del paso anterior.
  3. 3
    Ve a tu carpeta de proyecto: cd curso-datosO abre la terminal integrada de VS Code: Ctrl+Ñ.
  4. 4
    Inícialo: claude
  5. 5
    Inicia sesión con tu cuenta cuando lo pidaSe abrirá el navegador para autorizar el acceso.
  6. 6
    Prueba: pídele algo simpleEj.: "crea un archivo hola.py que salude por pantalla".

→ avanza paso a paso

PASO 05 · AGENTE IA

Codebuff

Otro agente de código para comparar: mismas tareas, otro asistente.

  1. 1
    Instala en la terminal: npm install -g codebuffUsa el mismo Node.js que ya instalamos.
  2. 2
    Ve a tu carpeta de proyecto: cd curso-datos
  3. 3
    Ejecuta: codebuff
  4. 4
    Inicia sesión la primera vez que lo abrasTe dará un enlace para crear la cuenta en el navegador.
  5. 5
    Prueba el mismo ejercicio que con Claude CodeAsí comparamos cómo responde cada agente.

→ avanza paso a paso

PASO 06 · CONTROL DE VERSIONES

Git

Guarda el historial de tu código: cada cambio queda registrado.

  1. 1
    Entra a git-scm.com/downloads y descarga para tu sistemaEn Mac suele venir instalado: prueba primero git --version.
  2. 2
    Instala con las opciones por defectoSiguiente en todas las pantallas — la configuración estándar funciona bien.
  3. 3
    Verifica en una terminal nueva: git --version
  4. 4
    Configura tu nombre: git config --global user.name "Tu Nombre"
  5. 5
    Configura tu correo: git config --global user.email "tu@correo.com"Usa el mismo correo con el que crearás la cuenta de GitHub.
  6. 6
    Revisa la configuración: git config --list

→ avanza paso a paso

PASO 07 · REPOSITORIO EN LA NUBE

GitHub

Tu código en la nube: respaldo, colaboración y publicación de proyectos.

  1. 1
    Entra a github.com y haz clic en Sign up
  2. 2
    Regístrate con el mismo correo que configuraste en GitElige un nombre de usuario profesional: te acompañará años.
  3. 3
    Verifica tu correo con el código que te envían
  4. 4
    Crea tu primer repositorio: botón New → nómbralo curso-datosMárcalo como público y agrega un README.
  5. 5
    Al final del curso publicaremos aquí tus aplicativos con GitHub Pages
